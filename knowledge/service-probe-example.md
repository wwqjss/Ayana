# 示例：服务探测知识条目

这是发行版自带的**示例**知识结构，不含任何真实资产。

## 用途

说明如何为「服务 + 端口 + 外部探测」写知识条目。部署方复制本模板后，
把 `objects` 改成自己的 `资产:对象`，再补充调查与处置步骤。

## 关系

服务进程
→ 监听端口
→ 外部探测

任一异常都可能来自服务进程本身，也可能来自网络路径。

## 调查

1. 查看服务状态
2. 确认端口是否监听
3. 看服务日志
4. 对比外部探测是否同时失败

## 处置

通过当前会话选定的 SSH 账号组和 Ayana MCP `host.exec` 调查或处置，变更保留写台账与审计。命令成功后还需核对服务、端口或探针的恢复证据；本示例不包含自动重启规则。
