### P4.1 幂等台账

| 改动 | 语义 |
|------|------|
| schema **v19** | `lease_expires_at` / `target` / `params_hash` / `claimed_by`，迁移幂等 |
| 状态机 | `claimed · done · failed · released · **unknown**` |
| `claim_write` | 原子条件 UPDATE（`status IN ('released','failed')`）防并发双 claim |
| 租约过期 | **转 `unknown`**，不等于未执行，禁止自动重放 |
| `done` | 永久拒绝 |
| `failed` | 默认不可重试，需 `retry_safe=True` |

**验收** [代码已证实 + 单测]：并发 claim/reclaim 单赢家、重启 unknown、租约过期 unknown、幂等键随参数变化。

### P4.2 统一写路径

| 入口 | 处理 |
|------|------|
| MCP `host.exec` | **读写分离**：`classify_shell_command` 三态；read 通道拒写/未知；写→claim→exec→`classify_exec_result`→done/**unknown**→审计 |
| ActionService | 可选注入 `write_ops`；派发前 claim，结果 done/unknown 落账；`no_replay` 保留 |
| `promconfig._retry_exec` | 写类 tokens **单次执行**，禁止盲重试（原函数现无调用方，仍收紧） |
| `/ws/terminal` | 会话审计补 `bytes_in/out`；认证+`shell.interactive` 策略保留；**不做逐键审批** |
| `deploy-pubkey` | 必须 `confirm=true`；审计含 `already_present` |

**验收** [实测已证实] kanata 冒烟：

```
read-channel reject → write_not_allowed_on_read_channel
read exec uptime    → classified=read
write touch …       → exec_state=success, action_key=nerv:exec_shell:68180cfa…
重复同命令           → idempotent_block
```

## 3. 幂等状态机与 unknown

```
        claim                 complete(ok)
  ──────────────► claimed ──────────────────► done   (永久拒绝)
   ▲                 │ │
   │                 │ └─ complete(not ok, 已确认失败) ─► failed ─(retry_safe)─► claimed
   │                 │
   │                 ├─ 超时/断连/异常 ─► unknown ─(人工核验 confirmed_safe)─► released ─► claimed
   │                 │
   │                 └─ 租约过期 ─► unknown   (≠ 未执行)
   │
 released ◄── release_write(confirmed_safe)
```

**红线**：`unknown` 不得自动重放；租约过期 ≠ 失败；`done` 一票否决。
