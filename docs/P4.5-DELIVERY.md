## 2. 一键部署脚本

`deploy/ayana-setup.sh`：

```bash
# 全新环境
sudo bash deploy/ayana-setup.sh init --git https://github.com/wwqjss/Ayana.git \
  --branch speed-supreme --prefix /opt/ayana --data /var/lib/ayana --conf /etc/ayana

# 更新（自动备份 → 拉取 → 重启 → 健康检查；失败自动回滚）
sudo bash deploy/ayana-setup.sh update

# 回滚上一版代码
sudo bash deploy/ayana-setup.sh rollback

# 状态 / 健康
sudo bash deploy/ayana-setup.sh status
sudo bash deploy/ayana-setup.sh health
```

- 自动生成 `config.json` / `secrets.json`（**永不入库**，`chmod 600`）
- systemd 单元名随 prefix（`/opt/ayana` → `ayana.service`，沙箱不冲突）
- 依赖：venv + `pip install -e`
