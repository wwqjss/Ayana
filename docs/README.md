建议先完成安装与首次设置，再登记一台主机并运行一次正常的连接测试。生产业务验收由使用者选择时间和目标，不需要为了检查安装而制造故障。

日常状态应分别观察：

- **原生任务**：会话是否正在执行、已中断或有结果待核对。
- **工单**：当前故障代次是否仍未关闭。
- **恢复证据**：是否已有与当前目标、类型和代次匹配的验证记录。

任务完成、命令成功、告警消失和故障恢复具有不同含义，界面与审计会分别记录。
