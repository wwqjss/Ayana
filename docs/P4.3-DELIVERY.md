## 1. 实际调用链与状态流转

```mermaid
flowchart TD
    AM[Alertmanager webhook] --> EP[alert_episodes]
    EP --> INC[IncidentService.upsert_from_episode]
    INC --> SB[SessionBridge.ensure_session]
    INC --> AI[AutoInvestigator.offer<br/>非阻塞]
    AI --> Q[investigation_jobs<br/>queued]
    Q --> W[worker tick<br/>全局并发≤2]
    W --> R[running + 租约]
    R --> M["MimoSessionClient(readonly_env)<br/>mimo run"]
    M --> MCP["MCP readonly 模式<br/>拒写+审计"]
    M --> P[解析结构化 JSON]
    P --> EV["events.auto_investigation<br/>结论进时间线"]
    P -.-> K[知识仅 speculation<br/>不得 verified=result]
    P --> D[done/partial/failed/timeout]
```

| 状态 | 含义 |
|------|------|
| `queued` | 待调查（offer 幂等入队） |
| `running` | 租约占用中 |
| `done` / `partial` | 结论已写时间线 |
| `failed` / `timeout` | 结束且进冷却，不自动重试 |
| 租约过期（重启） | → `failed`，不永久卡死 |

## 4. 证据与结论

结构化 JSON：`status / symptoms / facts[] / hypotheses[] / unconfirmed[] / next_steps[] / root_cause`。

- 事实 vs 推测 vs 建议分字段；**无证据 root_cause 强制 `unknown`**
- 结论写入 `events.auto_investigation`（保留轮次历史，不覆盖）
- MiMo 输出非 JSON → `partial` + `raw_excerpt`，**不伪造成功**
- **调查完成 ≠ 恢复**：不自动 close 仍 open/firing 的事件（单测锁住）
