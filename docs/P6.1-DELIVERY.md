# P6.1 闭环断链修复 · 交付

## 断链（P6 审计）
`auto_investigate._finish` 止于 events/knowledge；`ops_loop.run_action_and_verify` / `maybe_close` 无调用方；调查与 autonomous Action 两模块独立。

## 修复
1. `_run_job` 调查完成后 → `_close_loop`（同一 Incident）。
2. `_decide_remediation`：结论 `suggested_action` 或写权限 MiMo 会话 DECISION_PROMPT 产出 JSON。
3. `execute` → `ops_loop.run_action_and_verify` → `ActionService.autonomous_execute` + `verify` → `maybe_close`。
4. `human`/失败/无进展 → `ops_loop.escalate`（need_human + 通知）。
5. 软约束：`note_round`（3 轮无进展 / 同方案 2 次）仍强制。
6. 默认 `auto_investigate.enabled=true` + `closed_loop=true`；写决策用非 readonly `MimoSessionClient`。
7. `/api/ops/loop/{id}` 增加 investigation / closed_loop 状态。

## 调用链（目标）
`Alertmanager webhook → AlertIngest → Incident.upsert_from_episode → _touch_session → AutoInvestigator.offer → _run_job → _investigate(readonly) → _close_loop → decision → ops_loop.run_action_and_verify → ActionService.autonomous_execute → verify → maybe_close / escalate`

## 隔离 E2E（tests/test_p61_closed_loop_e2e.py）
| 场景 | 结果 |
|------|------|
| 修复成功 | autonomous Action + 审计 + 结案尝试 |
| 修复失败 | 轮次记录 / need_human |
| 重复告警 | 同代不双执行 |
| 进程重启 | 租约过期→failed，不重放写 |
| 证据不足 | decision=human → need_human |
